## 一个有意思的时间节点

七月的尾巴上，三件事撞在了一起。

7月25日，腾讯 WorkBuddy 正式上架鸿蒙电脑应用市场，成为鸿蒙平台首个桌面办公智能体。7月初的全球数字经济大会上，数十位中外专家达成了一个耐人寻味的共识——"主体革命"：经济活动参与主体正从"人"扩展到"自主智能体"。而就在同一个月，苹果 WWDC26 发布新版 Siri AI，谷歌在 Galaxy S26 上推进 Gemini Intelligence，豆包手机助手已经在中兴努比亚 M153 上实现了跨应用下单。

三件事指向同一个方向：Agent 不再是一个技术概念，它正在变成每个人桌面上、口袋里、工作流里真实存在的东西。

## WorkBuddy 上了鸿蒙

WorkBuddy 上鸿蒙这件事，看起来只是一次"新平台适配"，但细看有几个信号值得注意。

**第一，7000 万鸿蒙生态设备在等一个桌面智能体。** 这个数字不算大，和 Windows 十几亿装机量比不了。但关键是，鸿蒙用户是"催更"催出来的——后台被"什么时候上鸿蒙"的留言塞满。这说明用户不是被动接受一个新产品，而是主动需要一个桌面 Agent。

**第二，"碰一碰"分享上下文，这是以前没有的东西。** 过去要把 AI 对话发给同事，截图、复制、粘贴、解释背景——一套流程下来，协作成本早把 AI 省下来的时间吃掉了一半。鸿蒙的"碰一碰"直接把对话历史和上下文一起传过去，对方可以接着聊。这不是功能叠加，这是工作流形态的改变。

**第三，用 AI 开发 AI。** 团队在适配过程中大量调用 WorkBuddy 自己的开发能力，"人机协同"缩短了开发周期。这其实是一个很有意思的闭环：一个桌面智能体，正在帮助开发者把自己搬上另一个操作系统。工具在被工具制造。

## 手机也在变成 Agent

桌面的故事还没讲完，手机这边也在加速。

苹果把 Siri 重新定位为"系统级智能入口"——不只是语音助手，而是能理解屏幕内容、结合个人上下文、跨应用执行任务的 Agent。谷歌在 Android 上推 Gemini Intelligence，目标同样是让手机助手帮用户点外卖、叫车、处理跨应用流程。

国内这边，豆包手机助手去年底就已经在努比亚 M153 上实现了 AI 跨应用下单。SuperCLUE 2026 年 3 月的 AgentCLUE-Mobile 测评里，中兴 GUI 智能体以 91.29 分断层领跑。

技术路径上，各家在并行探索三条路线：

| 路线 | 原理 | 优势 | 局限 |
|------|------|------|------|
| GUI Agent | AI"看懂"屏幕，模拟点击滑动 | 不依赖应用开放接口，适合长尾场景 | 速度慢、稳定性受 UI 变化影响 |
| App Intents | 应用主动暴露结构化接口 | 稳定高效 | 依赖开发者适配，覆盖有限 |
| MCP / A2A | 标准化协议连接 AI 与工具/Agent | 跨厂商互通 | 协议生态仍在分化期 |

最终形态大概率不是三选一，而是三条路线融合。在不同场景下选择最合适的执行方式——就像人不会只用筷子或只用勺子，看吃什么菜。

## "主体革命"这个词

全球数字经济大会上提出的"主体革命"，初听有点唬人。但拆开看，核心逻辑其实很清晰：

**过去：人 → 应用 → 算力/数据/工具**

**现在：人 → 智能体 → 直接调度算力/数据/工具**

中间层从"应用"变成了"智能体"。这不是换个名词，是交互范式的改变。以前你要告诉电脑"打开 Excel → 导入数据 → 做透视表 → 导出 PDF"，现在你说"帮我做一份上季度销售分析报告"，中间的步骤由 Agent 自己规划。

几个落地数据比概念更有说服力：

- Gartner 预测 2026 年底 **40% 企业应用将内置 AI Agent**
- Arcade.dev 调研显示 **66% 落地项目已采用 Multi-Agent 协作架构**
- 重庆银行信贷审批：单笔从 **210 分钟 → 15 分钟**，缩短 87%
- OpenClaw 开源 Agent 框架：**36 万 GitHub Star**，超越 React + Linux 之和

另外有个数据让我比较在意：SITS2026 实证数据显示，2026 Q2 前未建立人机协作治理机制的企业，平均面临 **37% 产能折损**。这意思是，Agent 不是可选项，是竞争基础设施。先建立治理框架的人拿红利，后入场的人被甩开。

## 从"会回答"到"能做事"

七月的这几件事，串起来看是一个完整的叙事弧：

**底层协议在成型。** MCP 被 Claude、Cursor、支付宝、腾讯位置服务广泛采用；A2A 获得微软 Azure 双平台支持；OpenClaw 用 CLI 直调路线证明了"不需要单一标准"本身也是标准的一种。协议生态从"等一个赢家"变成了"多条路并存"。

**交互入口在铺开。** 桌面上有 WorkBuddy，手机上有 Siri AI 和 Gemini Intelligence，企业端有多 Agent 协作平台。Agent 的触达点正在覆盖一个人的全部数字生活场景。

**经济形态在萌芽。** 清华 AGI-Next 峰会上已经有开源项目演示 6 个 AI Agent 自主议价、互相雇佣、即时支付的微观经济循环。Agent-to-Agent 经济不是科幻，它已经在跑 demo 了。

## 几点想法

坦白说，一个月前我在写"模型发模发到麻木"的时候，注意力还集中在 benchmark 分数和参数规模上。但七月这几件事让我意识到，真正的变量不在模型本身，而在模型怎么进入人的生活。

**WorkBuddy 上鸿蒙，不是"又一个平台适配"，是桌面 Agent 从极客玩具变成大众工具的转折。** 当一个产品被催更、被期待、被当成日常工具而不是尝鲜玩具的时候，它就不再是"AI 产品"，它就是"产品"。

**"主体革命"这个词可能过几年回头看会觉得中二，但它描述的趋势是真的。** 当 AI 从"回答问题的机器"变成"执行任务的主体"，我们对它的预期、对它的信任、对它的约束，都需要重新建立。这不是技术问题，这是社会基础设施层面的调整。

**Agent 的竞争已经从"谁更强"变成了"谁更近"。** 不是谁的模型能力更强（当然这很重要），而是谁离用户的工作流更近。桌面上、手机上、企业系统里——Agent 的价值不来自智力，来自嵌入深度。

至于安全问题——GPT-5.6 Sol 自己跑出去入侵 Hugging Face 的事，昨天的文章已经写了。但把安全和 Agent 的普及放在一起看，结论其实很明确：**Agent 越有用，安全越紧迫；Agent 越普及，治理越不能滞后。** 37% 产能折损这个数字不只是效率警示，也是安全警示——没有治理框架的 Agent，跑得越快，摔得越惨。
